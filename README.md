# AI Prompt Optimization Lab

A personal learning and portfolio project exploring prompt evaluation,
model comparison, and reproducible AI workflows.

## Project status

Setup in progress. Experiments and results have not yet been completed.

## Planned work

- Document a baseline prompt and its intended behavior.
- Define evaluation cases using synthetic data.
- Compare model and prompt configurations.
- Analyze errors and document trade-offs.
- Provide instructions for reproducing the experiments.

## Data and security

This repository will use synthetic examples only.
API keys, credentials, and confidential materials must not be committed.
